System Design

Architecture and Requirements

The NavFusion system collects sensor data, performs filtering and AI-based correction, and outputs position, orientation, and velocity in real time.

Data Collection

Collect IMU and GNSS data with timestamp synchronization for logging and fusion.

Sensor Fusion

Use Kalman filtering or equivalent techniques to reduce noise and support transitions.

AI Correction

Apply machine learning to improve inertial estimates and reduce long-term drift.

Primary Functional Requirements

  • Real-time drift correction with target latency under 50 ms per sample
  • Seamless switching between GPS-active and GPS-denied modes
  • Storage of collected data for later post-processing
  • Deployment on both ground and aerial platforms

Hardware / Software Targets

  • IMU sampling rate of at least 100 Hz
  • Battery runtime target of 6 hours
  • MATLAB / Simulink deployment workflow
  • Logging support for MAT and CSV formats
