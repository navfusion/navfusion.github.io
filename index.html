NavFusion

AI for Robust Navigation in GPS-Denied Environments

NavFusion is a senior design project focused on improving localization for mobile robots and vehicles when GPS becomes unavailable, spoofed, or unreliable. The system combines IMU sensing, GNSS integration, filtering, and AI-driven drift correction to support real-time navigation on embedded hardware.

Purpose

Why this project matters

GPS denial and interference create serious challenges for autonomous navigation. NavFusion addresses this by enhancing inertial navigation with AI, allowing a vehicle to continue estimating motion even when GNSS signals degrade.

Reliable Localization

Maintain meaningful navigation estimates during GPS-denied operation.

AI Drift Correction

Use machine learning to reduce IMU drift over longer deployments.

Embedded Deployment

Run the solution on real hardware for testing on mobile platforms.
